پچ نسخه «روزانه»

این فایل‌ها را دقیقاً با مسیرهای داخل ZIP جایگزین کنید.
هیچ فایل workflow یا فایل مربوط به GitHub Actions داخل این ZIP نیست.

تغییرات اصلی:
- نام برنامه: روزانه
- رابط کاملاً راست‌به‌چپ
- خروج با دو بار فشردن Back در فاصله ۲ ثانیه
- ساعت و تاریخ خبر بر اساس Asia/Tehran و تقویم شمسی
- مرتب‌سازی اخبار: جدیدترین‌ها اول
- دریافت موازی منابع برای بروزرسانی سریع‌تر
- ترجمه خودکار اخبار غیرفارسی به فارسی، بدون محدودیت ۱۲ خبر
- دکمه ترجمه دستی برای خبرهای ترجمه‌نشده
- تبدیل نرخ دلار TGJU از ریال به تومان (تقسیم بر ۱۰)
- بازطراحی هدر و آیکون برنامه
- نام اعلان‌ها و متن‌های کاربری از «نبض» به «روزانه»
- فونت UI به صورت ثابت روی Sans-Serif سیستم تنظیم شده است
